The format

https://wa.me/<number>?text=<message>. The number is in full international format. The message is optional and must be URL-encoded.

Rules

Use the country code first, for example 91 for India. Do not use a plus sign, brackets, spaces or dashes. Do not start with zeros. Encode spaces as %20, which the tool does for you.

Common mistakes

Adding +91 instead of 91. Keeping a leading 0 in the local number. Putting spaces in the message without encoding. Using wa.me/ without any number.

Frequently asked questions

What does wa.me mean?

wa.me is WhatsApp's official short domain for click-to-chat links.

Can I use api.whatsapp.com instead?

Yes. It is the longer form of the same link, and wa.me redirects to it.

How do I add a line break in the message?

Use %0A for a new line in the text parameter.
