How to create a WhatsApp link

A WhatsApp click-to-chat link has this format: https://wa.me/NUMBER?text=MESSAGE. The number must include the country code and no plus sign, spaces or dashes. The message must be URL-encoded, and this tool does that for you.

Frequently asked questions

How do I create a WhatsApp link with a message?

Enter the number with country code, type your message, and the tool builds a wa.me link you can copy.

Do I need to add a plus sign or zeros before the number?

No. Use the country code followed by the number, for example 919876543210.

Is this WhatsApp link generator free?

Yes. It runs in your browser, and your number and message are not sent to any server.
